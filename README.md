# PersonaKey – Secure Personalized Password Generator

PersonaKey is a modular, OOP-driven password generator built using **TypeScript** and **React**.  
It helps users create strong, unique, and customizable passwords to prevent password-reuse vulnerabilities.

---

##  Overview

PersonaKey focuses on three core goals:

### **1. Modular OOP Architecture**
Built using clean and extensible TypeScript classes to handle:
- Password patterns  
- Validation rules  
- Character-set management  

This approach ensures clarity, reusability, and easy future expansion.

### **2. Configurable and Flexible Password Generation**
Users can customize:
- Password length  
- Uppercase, lowercase, digits, and symbols  
- Optional personalized patterns  

This results in stronger, more adaptable password generation to fit different security needs.

### **3. Solving Password Reuse**
PersonaKey encourages safer password habits by:
- Generating strong, unique passwords every time  
- Providing a simple, intuitive React interface  
- Helping users avoid using the same password across multiple platforms  

---

## Key Features

- OOP-based TypeScript implementation  
- Configurable character sets and complexity  
- Optional user-defined patterns  
- Real-time password preview  
- Password strength indication  
- Responsive React UI  

---


---

## Security Notes

- All password generation is done **locally in the browser**  
- No data is stored or transmitted  
- Uses `crypto.getRandomValues()` for secure randomness (Infuture version)

---

## Purpose

PersonaKey is designed as a learning and portfolio project to practice:
- OOP design in TypeScript  
- React component architecture  
- Secure UI/UX thinking  
- Problem-solving around real-world password hygiene issues
